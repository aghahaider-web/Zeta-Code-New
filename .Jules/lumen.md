## 2024-05-24 - Interactive Micro-transitions (Hover States)
**Learning:** Some bento or grid cards in the codebase were styled heavily with inline styles, meaning pseudo-classes like `:hover` were implemented globally in `app/globals.css` (e.g. `.industries-card:hover`) but missing the class assignment on certain pages (like `app/(public)/page.tsx` for the "Industry Fit" grid), creating a disjointed user experience where some identical-looking elements react to hover and others do not. Furthermore, smooth transitions like `transition: border-color var(--duration-fast) var(--ease-standard)` were missing in the inline styles of some instances.
**Action:** When implementing repeating interactive grid items across pages, verify that globally declared interaction classes (like `.industries-card` or `.services-bento-card`) are actually applied to *all* instances of that pattern. Also, ensure the inline `transition` property matching the design tokens (`--duration-fast` and `--ease-standard`) is present for a smooth and premium feel on interactive hover/focus state changes.
