## 2023-10-27 - Smooth Hover Transitions on Cards
**Learning:** Interactive visual elements like cards need smooth hover transitions to feel polished. The codebase uses `var(--duration-fast)` and `var(--ease-standard)` tokens for these micro-transitions.
**Action:** Always check for missing hover states on interactive cards and apply the standard CSS transition tokens to smooth out any abrupt changes.
