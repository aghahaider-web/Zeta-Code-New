# Phase 2 — Industry Page: Property & Interiors
Route: /industries/property-interiors

## Buyer concerns
Clients are making high-value, emotionally significant decisions. They
want to see taste, capability, and process clarity before committing —
generic stock-styled sites read as low-credibility.

## Common website/conversion failures
- Portfolio work shown without process or scope context
- No distinction between service tiers (consult vs. full project)
- Weak "get started" path — unclear what happens after first contact
- Design that doesn't reflect the firm's actual aesthetic standard

## Decision journey
Browse portfolios for aesthetic fit → shortlist based on scope match →
initial consultation → proposal → engagement.

## Trust requirements
Real project documentation (not stock imagery), clear process explanation,
credentials/experience, responsive initial-consult path.

## Quote/appointment flow recommendation
Discovery-call booking rather than instant quote — property/interiors
decisions typically need a conversation before scoping.

## Relevant services
Conversion websites, SEO (portfolio/local search intent), Care plan

## CTA
Book a discovery call to scope a site that reflects the standard of your
actual work.
