## 2026-08-24 - Cache Intl.DateTimeFormat
**Learning:** Calling `new Date().toLocaleString()` repeatedly (especially in loops or re-renders) forces the JS engine to instantiate a new `Intl.DateTimeFormat` object each time. While this works, it blocks the main thread and severely degrades performance. Also, `Intl.DateTimeFormat.format()` throws on invalid dates whereas `toLocaleString()` returns "Invalid Date", which might cause React runtime crashes if dates aren't validated.
**Action:** When rendering lists of dates or executing multiple formats, cache `Intl.DateTimeFormat` (using `useMemo` in React Client Components or a module-level constant in Server Components) and use `.format(new Date())` to prevent main thread blocking and boost overall performance. Ensure dates are valid beforehand.
