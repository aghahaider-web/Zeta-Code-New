## 2025-02-23 - Removed undefined radius variable
**Learning:** Found `var(--radius-sm)` used on buttons on `/services/conversion-websites/page.tsx` and `/about/page.tsx`. This variable isn't defined anywhere in the codebase (the design system hardcodes `border-radius: 2px` via the `<Button>` component and global styles). Using undefined variables leads to silent fallbacks which can break intended visual consistency.
**Action:** When adding or updating buttons or other interactive elements, always use the central `<Button>` component which encapsulates the correct radius and hover styles instead of raw `<Link>` tags with inline styles. If inline styles are needed, stick to the hardcoded  or  conventions defined in the tokens, avoiding assumed variables.
