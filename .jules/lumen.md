## 2025-02-09 - Typography and Rhythm Consistency
**Learning:** Hardcoded line-height variables (like `var(--leading-snug)`) on display typography disrupt the cohesive, tighter global scale (`var(--leading-tight)`) defined on `h1`-`h6` elements. Also, the thematic rhythm is broken when heading margins randomly alternate between `var(--space-3)` and `var(--space-4)` instead of following a logical structure (e.g., smaller margin before `<p>`, larger before a grid).
**Action:** When updating a page, verify heading element styles (especially sizes like `--text-2xl`) don't unnecessarily override global typography tokens, and maintain structured logic for spacing scales between headings, paragraphs, and sections. Ensure interactive elements correctly use existing global hover classes (like `.industries-card`).
